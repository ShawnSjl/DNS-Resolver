# Local DNS Server Proposal

### An outline of the project you want to implement: what do you to build, and what do you want to learn from it?

In this project,
we will implement a local DNS server that can be used to resolve domain names to IP addresses.
we will also implement a controller that could be used to interact with the server when it is running in the background.

In this project,
we want to learn more than simple DNS-related theory.
Such as learning how to implement a DNS resolver in a programming language,
instead of learning notes of the lecture.
The DNS server is a good goal that it could be used on our PCs.

### Any stretch goals you think may be difficult but nice to have

The first stretch goal is supporting the Resource Record cache.
The second stretch goal is supporting the blacklist feature for some domains like advertisements.
And we will come up with more stretch goals based on the progress of the project.

### Any tools, libraries, or language(s) you intend to use (doesn’t need to be a final list)

In this project,
we will use Go to implement the DNS server and the controller.
Here are some libraries that we will use:

1. [readline](https://github.com/chzyer/readline) for the controller's CLI
2. [dns](http://github.com/miekg/dns) for resolving DNS protocol

### How you plan to use AI to help you

Same like previous projects,
we will use AI to guide us to learn deeply about the DNS protocol and the Go language during the development.

We stick to the old-school programming, 
which is to write the code by ourselves.
In our implementation, we will not copy and paste any code generated by AI.
